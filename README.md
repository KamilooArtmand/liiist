# Liiist

Make a list of anything: products, books, apps, links, people, brands, cities, places, businesses, movies.

- Light theme by default (dark available), token-based design system in `src/styles.css`
- Liquid glass UI on a white / black / gray palette, Inter Variable
- Full Lucide icon bank, custom colors, cover images per list
- Unique id per list, likes, comments, sharing, view counter
- Motion by `motion`, latest React 19, Vite, Tailwind 4, TypeScript

Sign in with username `Kamiloo` and password `Kamiloo`. This is a client-side demo gate only; data lives in `localStorage`.

```
npm install
npm run dev
```
